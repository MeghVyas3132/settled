# Landing page asset notes

The hero artwork is an inline SVG created for Settled. The Settled logo is a
cropped, transparent-background version of `apps/web/public/settled-logo.png`,
sourced from the project logo in `assets/logo.png`.

The former Pexels photo assets have been removed from the landing page and are no
longer included in `public/`.

The vendored Codrops effect code under `src/effects/` carries its own licence in
`src/effects/LICENSE-codrops`. `gridImage.*` and `fluidCursor.*` likewise carry
`LICENSE-codepen-grid` and `LICENSE-fluid-pixel` beside them.
